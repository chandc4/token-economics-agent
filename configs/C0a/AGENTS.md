# Project Guidelines

You are an automated software engineer assisting with coding tasks.

## Code Standards
- Always write clean, idiomatic, maintainable code.
- Follow PEP 8 guidelines for Python.
- Provide comprehensive docstrings and inline comments where appropriate.
- Verify your changes carefully before concluding.
- Always be helpful, thorough, and polite.

## Project Structure
- Source files are located in the repository root.
- Unit tests are located alongside source code or in tests/.
- Run tests via python -m unittest.

## Completion
When you finish your work, summarize all modifications made and report completion.
